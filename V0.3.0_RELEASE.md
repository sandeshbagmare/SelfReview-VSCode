## 🧪 How to Install & Test

### Method 1: Install from VSIX
```bash
code --install-extension selfreview-0.3.0.vsix --force
```

### Method 2: Clone from GitHub
```bash
git clone https://github.com/sandeshbagmare/SelfReview-VSCode.git
cd SelfReview-VSCode
npm install
npm run compile
code --install-extension selfreview-0.3.0.vsix
```

### Test It:
1. Open any git repository in VS Code
2. Press **Ctrl+Shift+R** (or Cmd+Shift+R on Mac)
3. Review panel opens!
4. Try all features:
   - Navigate with ← → buttons
   - Add comments on lines
   - Check Activity tab
   - Delete comments
   - Export comments
   - Run AI review
